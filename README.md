# Afterword · 让单词留在记忆里

个人词汇学习 Web 应用：以自己的六级试卷为词书，用选义、分轮回忆、记错重学、拼写和到期复习完成记忆闭环。适配电脑与 Pad 尺寸，提供晴空／纸白专注界面。无需模型 API、账户或云服务；可选的大模型接口默认关闭。

## 启动

需要 Node.js **22.13 或更新版本**（使用内置 `node:sqlite`）。没有第三方运行依赖，无需执行 `npm install`。

```sh
cd Afterword
npm start
```

浏览器打开 **http://127.0.0.1:3210**。终端保持运行；结束时按 `Ctrl+C`。再次执行启动命令会继续使用原来的数据库。若端口被占用，可执行 `PORT=3212 npm start`，并打开对应地址。

数据默认存放在项目目录的 `data/cet6.sqlite`；SQLite 的 WAL/SHM 文件也在这个目录。默认仅监听 `127.0.0.1`，只能在运行服务的电脑打开。现在提供**可选的单用户私人部署模式**：密码登录、HTTPS 代理、会话过期、Docker 数据卷、健康检查与一致性备份，参见 [部署与发布检查](DEPLOYMENT.md)。配置前仍禁止直接把无登录的本机模式暴露到局域网／公网。开发时可用 `npm run dev`，修改后浏览器需刷新。

## 七日复习日历

首页与学习记录展示当前已学词的下一次到期安排，区分“现在可复习”和“今日稍后到期”。以前积压的词与没有安排日期的旧词归入今天，新词不会提前计入复习量。同一词在多套试卷中出现仍只计一次。

点击日期查看词条和释义（每页 50 词），今天可直接进入到期复习；查看未来日期不会提前开始学习或修改进度。日历以北京时间凌晨 4 点分日，支持手动更新。它是现有到期计划的快照，不是未来总负荷预测：新学、遗忘或再次完成复习后，安排会变化。

## 录入与归档

1. 在“试卷”创建考试年月和套卷编号，例如“2025年6月 · 第1套”。编号留空表示未注明。相同年月与编号不会重复创建。
2. 点击“录入词条”，选择试卷，粘贴以下任一格式。
3. 点击“预览词条”后逐行检查，可修改英文或释义、排除异常行，并选择合并或替换冲突释义。修改后先“重新检查”，再“确认保存”。

Markdown 两列表格：

```text
| 英文 | 中文释义 |
| --- | --- |
| accumulate | 积累；积聚 |
| in the long run | 从长远来看 |
```

每行一条文本：

```text
accumulate = 积累；积聚
in the long run = 从长远来看
```

也可以从表格工具复制英文、中文两列（用制表符分隔）。页面内提供格式示例和可复制给大模型的提示词。手动录入采用约定格式解析；以后启用大模型接口后，可在“用大模型整理原文”中处理文章或试题原文。输入中的 HTML 只作为普通文字显示。

复制表格时，单元格中的 `|` 会原样保留，多余的空列也会被提示为异常。若草稿对应的试卷已被删除，输入与预览修改仍会保留，并要求重新选择归档试卷。切换归档不会静默丢弃草稿，保存前必须重新检查。请求处理中会暂时锁定输入，防止预览和保存的内容不一致。

录入文字、模型原文、预览修改及排除/合并/替换选择会自动临时保存到**当前标签页的 sessionStorage**，刷新后恢复；恢复的预览必须重新检查并明确确认，绝不自动入库或重新调用模型。恢复不会复用旧的保存请求标识。它不跨设备，不进入词库 JSON 备份，也不保证关闭标签页、清理浏览器或隐私模式后仍可恢复；最长保留 7 天，约 250 万序列化字符以内。浏览器限额或禁用存储时会明确提示临时保存失败，不阻止手动录入。离开有内容的页面时会请求浏览器显示提醒（部分移动浏览器可能不显示）。

确认入库、恢复词库备份或主动退出登录后会清理当前标签页草稿。“清空草稿”需要再次确认，不影响已入库内容。共用电脑上请清空草稿；不要把浏览器临时保存当作正式备份。

- 每条只有英文与中文释义；单词和短语统一管理。
- 英文匹配忽略大小写与多余空格，不合并词形变化。展示沿用该英文首次收录时的写法。
- 同卷相同英文和释义跳过；不同释义默认合并，也可替换。不同试卷分别保留释义和来源；全局复习合成一张卡。
- 在词条“查看”中按试卷编辑、删除。更换英文后关联已有词则沿用其进度，新词从未学开始。
- 删除试卷只影响该卷关联；仍有其他试卷来源的词条及掌握状态保留。
- 修改或删除当前学习组中的词条会结束该组，已记录的掌握状态保留；普通追加导入不改变进行中的词卡快照。
- 解析异常不会静默丢弃。每批最多 10000 行，原始文本最多 200 万字符，英文最多 300 字符，单次录入释义最多 5000 字符。

## 学习流程

首页分开显示“复习旧词”和“学习新词”，不强制先复习。可以选单套或全局、到期／未学／不熟／全部，默认每组 10 词，支持 1—100 词；到期词最早优先，其余按最近练习时间轮转。学习偏好可保存默认组数、每日目标、学习后拼写、复习后拼写、默认口音和背景。

### 新词与不熟词

**收藏专项练习**：在词库选择“已收藏”后点击“练习收藏词”，或在学习设置中选择“已收藏（专项练习）”。支持单套／全部试卷、分轮记忆或仅拼写；按最近练习时间轮转，不跟随词库搜索文字。开始时固定本组词条，途中取消收藏不会中断，下一组才按最新收藏重新选词。“继续下一组”保留练习状态范围和试卷。提前练习已掌握词不延长原复习间隔，答错仍会按正常规则重新安排复习。收藏组可备份恢复，需使用支持该范围的新版本。

1. **选义初识**：看英文，选择词库里的中文释义；不会时直接看答案。最多四项，干扰项也来自真实词库，词库不足时减少选项，不生成虚假释义。
2. **词义回忆三轮**：看英文，在心里回忆中文，再选“认识／不认识”；复习旧词额外提供“模糊”。正确的词放到队尾，和其他词交替出现。第四轮仍考词义，不再混入反向回忆；与教程描述的四次词义确认一致。
3. **拼写巩固**：四轮全部完成后按设置进入拼写。输入完整单词或短语；忽略大小写、多余空格，但不忽略缺字、标点或词形差异。也可单独选择“只练拼写”。

新组使用 `protocolVersion: 2`。旧分轮会话没有此字段，仍按原来的第四轮反向回忆继续；答错重置也保留原协议，不在升级时改变进行中的训练。两种会话都能在 v2 备份中恢复；未知训练协议拒绝恢复。

### 已掌握词与纠错

- 已掌握词从英中回忆开始；认识并核对正确即可通过记忆部分，之后按设置拼写。
- “认识”不会立刻计为完成：先展示答案，再确认继续；发现记错可点“记错了”或按 `C`，不用退出重开。
- 不认识、模糊、选错或纠错会立即标记不熟，并清零复习间隔。继续后隔最多 3 个其他词重现，记忆部分从第一轮重新学习；拼写错误则重新拼写。单词组只有一词时立即重现。
- “上一词”是只读回看，不撤销已提交记录。当前词的核对状态不变。
- 通过记忆和所选拼写才标为已掌握、安排下次复习。默认间隔依次为 **1、3、7、14、30、60 天**，之后保持 60 天；提前复习不延后原计划。忘记后通过重新从 1 天开始。该规则不是 FSRS，也不是不背单词的专有算法。
- 小结展示本组完整通过数、曾记错词和“只练本组错词”。错词重练只针对当前小结，不复活已删除词条。

### 续学、语境与记录

- 每次操作写入 SQLite；刷新、关闭页面、退出专注或重启服务后可续学，连未确认答案和纠错状态都保留。全局仅一个学习组，多标签页过期操作返回 409 并刷新。
- 提前结束保留已确认完成记录和已发现的错误，不把待核对答案当作通过。旧版三阶段会话仍可继续完成，旧 API 默认模式也保留。
- 全局复习合并相同释义并保留来源；单套练习只展示所选试卷的释义。
- 记词页使用居中单列、浅蓝云色背景、顶部进度、底部判断控件；不会在作答前显示语境或笔记而泄露答案。核对后点击词义进入语境，卡片底部可切换语境、笔记与试卷来源；资料切换不会提交或修改作答。
- 词条可收藏，添加自己的原句、译文、搭配与记忆笔记；保存后在核对页显示。英／美发音和例句朗读使用设备提供的英语语音，无可用口音时提示，不冒充真人原声。
- 学习记录统计最近 14 天、连续学习天数和今日完成量。北京时间 04:00 换日，同日同词重复完成只计一次；按组开始时的状态区分新学与复习。旧版没有的逐日记录不会补造。
- 选义时数字键选择，空格看答案；回忆时 `1` 不认识、`3` 认识，旧词复习可用 `2` 模糊；核对页空格／Enter 继续、`C` 纠错。拼写框 Enter 检查。输入框和弹窗不触发学习快捷键。

在词库按来源、状态、收藏和中英文搜索筛选，**导出当前词表**得到 UTF-8 两列 TXT，可重新导入。它不包含笔记与学习进度；迁移完整数据请用 JSON 备份。

## 导入与学习保护

笔记与收藏支持跨页面冲突保护：打开编辑时记录原内容，保存时只合并本次实际修改的字段。例如，平板收藏一个词不会被电脑上的旧笔记表单取消；同时编辑同一项笔记时，后提交的不同内容会被拒绝，输入留在弹窗里，需先复制再重新打开核对。相同结果可重复提交，不影响其他字段。此保护针对笔记、例句、译文和收藏，不代表所有编辑接口均支持并发合并。

`PUT /api/words/:id/details` 必须携带 `expected`（编辑前完整的 `starred`、`note`、`example`、`translation`）。缺失返回 428，冲突返回 409；旧页面需刷新后使用。备份文件格式不变。

学习偏好同样支持字段级合并：只调整每日目标不会重置口音、背景或拼写选项；不同页面修改不同选项可以合并，同时修改同一选项则拒绝覆盖并保留表单输入。`PUT /api/preferences` 必须携带完整的原始偏好 `expected`，其他字段可以只提交需要修改的部分；缺失原始偏好返回 428，冲突返回 409。冲突后先记下当前修改，再刷新页面核对。

导入预览会提示是否影响当前学习组。确认保存涉及的释义变化后，受影响的学习组会结束，已记录的学习结果保留，避免旧词卡继续使用过时答案。纯重复、排除行和不属于当前试卷范围的变化不会中断该组。预览仅供核对，保存时仍会按最新数据重新检查。

导入的“替换释义”也支持删除原有的多余释义：即使新释义只是旧释义的一部分，也会真正替换，不再误判为重复跳过。重复行同样提供合并／替换选项，修改后须重新检查并确认保存。

## 备份与恢复

在“偏好与备份”下载完整 JSON v2，包含所有试卷、词条、复习计划、当前学习会话、收藏、语境笔记、学习偏好和完成记录。可迁移到其他电脑上的新版工具。支持读取旧 v1 备份，缺失的新字段使用默认值；旧应用不能读取新版 v2，避免静默丢失数据。数据库启动时兼容增加表与复习字段，不改变旧词条 ID。

恢复时先选文件、校验并预览数量，确认后整体替换现有数据。替换前自动保存一份完整旧数据到 `data/backups/before-restore-*.json`；如需撤销恢复，选择该文件再次恢复即可。损坏或不兼容文件不会覆盖现有数据。文件最大 30 MB。

每次恢复都会更新学习组标识，保留词卡、作答进度和历史统计。其他标签页或设备中恢复前的学习操作会被拒绝，刷新后才能继续，避免旧页面误改恢复后的进度。重复恢复同一份备份也会重新隔离旧页面。

浏览器缓存不保存词库，清理缓存不影响数据库。定期导出备份并另存一份。不要在服务运行期间仅复制 SQLite 主文件；使用网页导出的 JSON，或停止服务后复制整个 `data/` 目录。删除单个词条或试卷没有回收站，操作前可先导出备份。

## 以后接入大模型

接口默认关闭。现在不用填写密钥，也不会联网调用模型。页面中保留“用大模型整理原文”入口，在“数据与备份”可查看配置状态。

1. 将项目根目录的 `.env.example` 复制为 `.env`。
2. 填写服务商提供的 API 根地址、模型名和密钥，将 `LLM_ENABLED` 改为 `true`。
3. 重启 `npm start`，刷新页面。环境变量优先于 `.env`；配置只在启动时读取。
4. 在“录入词条”中选择试卷，展开“用大模型整理原文”，粘贴英文原文并点击“整理并预览”。
5. 核对英文和中文释义，必要时修改或排除，再点击“确认保存”。整理接口本身不写入词库。

配置项：

| 配置 | 默认值 / 用途 |
| --- | --- |
| `LLM_ENABLED` | `false`；仅 `true` 启用 |
| `LLM_PROVIDER` | `openai-compatible`，当前支持的适配器 |
| `LLM_BASE_URL` | 留空；API 根地址，包含服务商要求的版本路径，例如 `https://api.example.com/v1`；也接受完整 `/chat/completions` 地址，不会重复追加 |
| `LLM_MODEL` | 留空；服务商提供的文本对话模型标识 |
| `LLM_API_KEY` | 留空；仅服务端读取，不发给浏览器、不写入词库和备份 |
| `LLM_TIMEOUT_MS` | `45000`；可设置 1000—120000 毫秒 |
| `LLM_TOKEN_PARAMETER` | `max_completion_tokens`；若兼容服务使用旧字段，设为 `max_tokens`。两者仅发送所选的一项，固定上限 4096 |

适配器采用 [Chat Completions 请求格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：`model`、`messages`、`stream: false`，从 `choices[0].message.content` 读取结果。输出长度默认用 `max_completion_tokens: 4096`，可通过配置切换到 `max_tokens`（例如 [DeepSeek 文档](https://api-docs.deepseek.com/api/create-chat-completion/) 使用此字段）。不自动重试或猜测服务商，避免重复调用和费用。所选兼容服务需支持这些字段；不支持该协议的供应商应增加适配器，不要只替换地址。无需安装 SDK，没有绑定具体模型或服务商。

远程服务需使用 HTTPS，本机模型服务允许 `http://localhost`、`http://127.0.0.1` 或 `http://[::1]`。根地址不接受用户名、密码、查询参数和片段；请求不跟随重定向。`.env` 已加入忽略规则，静态服务不会提供配置文件。

启用后，只有点击“整理并预览”才会把输入的原文发给配置的服务，可能产生服务商费用。不会发送已有词库、备份或复习记录。接口状态只表示配置完整，不代表已实测连通。每次最多 20,000 字符、最多返回 100 个词条；模型格式异常、拒答、截断、超时或限流均保留原输入与已有词库，不自动重试。一次只允许一个模型请求。

### 预留接口与扩展点

- `GET /api/llm/status`：返回 `state`（`disabled` / `unconfigured` / `invalid` / `ready`）、`ready`、`provider`、`model`、`serviceOrigin`、`message`、`maxSourceLength`。不返回密钥。
- `POST /api/llm/preview`：传 `{ "paperId": "试卷 ID", "text": "英文原文" }`；返回与手动导入一致的 `rows`、`counts`、`ignored`，以及 `generatedBy: "model"`。未启用时返回 503，试卷不存在返回 404，输入错误返回 400，空结果返回 422，上游格式或连接异常返回 502，超时返回 504，请求忙或上游限流返回 429。
- 确认保存沿用 `POST /api/import/confirm`，继续使用去重、释义合并、重新检查和事务写入。
- `lib/llm.js` 的 `createLlmService()` 返回 `{ status(), extract(text, { source } = {}) }`。`source` 为下文的规范化来源；省略时使用通用英语材料提示词。以后增加供应商时保持此契约：`extract` 只返回经过校验的 `{ english, meaning }[]`，不修改数据库。
- `createApp({ llm })` 支持注入适配器。测试通过 `fetchImpl` 注入模拟响应，不使用真实密钥或付费请求。

## 考研英语文章扩展约定

当前已预留来源元数据、考试分类与提示词，仍然只支持六级试卷的创建、录入和复习。考研文章的管理页面、持久化和数据迁移尚未启用；`storageReady: false` 的类型不能作为可用录入目标。

`lib/sources.js` 统一定义来源，不用页面名称或数据库表名判断考试类别：

| `exam` | `kind` | 含义 | 当前可存储 |
| --- | --- | --- | --- |
| `cet6` | `paper` | 六级试卷 | 是 |
| `kaoyan-english-1` | `article` | 考研英语一文章 | 否 |
| `kaoyan-english-2` | `article` | 考研英语二文章 | 否 |

`normalizeSource(input)` 校验并返回统一字段；`sourceLabel(input)` 生成显示名称，不能用显示名称当唯一标识。六级由 `paperSource(paper)` 从原记录转换，沿用原 `id`、年月、套卷和标签。文章来源示例：

```json
{
  "id": "article-uuid",
  "kind": "article",
  "exam": "kaoyan-english-1",
  "title": "The value of curiosity",
  "examYear": 2025,
  "examMonth": null,
  "volume": null,
  "section": "reading",
  "articleNumber": 2
}
```

文章标题必填，最多 120 字符。年份可留空，填写时为 1900—2199；篇号可留空，填写时为 1—99。`section` 支持 `reading`、`cloze`、`translation`、`writing`、`other`，默认阅读。文章来源不使用六级月份和套卷字段。每篇文章应有自己的稳定 ID，同名文章不自动合并。

已提供的只读接口：

- `GET /api/source-types` 返回 `{ version: 1, profiles }`，每项包含 `exam`、`kind`、`label`、`storageReady` 和 `manualImportPrompt`。
- `GET /api/overview` 保留原来的 `papers`、`words`、`session`，增加 `sources` 和 `sourceProfiles`。`sources` 是六级试卷的通用视图，附带 `label`、`count`、`mastered`；读取时生成，不增加数据库表。
- 当前词条的 `words[].sources[]` 和复习卡来源仍通过 `paperId` 关联；其中词条来源的 `id` 是释义关联记录 ID，不是来源 ID。导入、删除、复习等写接口仍接收 `paperId`，尚无 `/api/sources` 写接口。

手动复制的整理要求和模型系统提示词共用考试分类。考研提示词关注文章语境义、论证关键词、逻辑表达和完整短语，继续只输出英文和中文释义。模型适配器已能接收文章元数据；现有 HTTP 预览接口只从服务端试卷记录构造来源，不接受客户端覆盖考试类别。文章标题不插入系统提示词，原文只作为用户消息传入。

### 正式接入时的实现顺序

1. 增加带版本号的事务迁移，将 `papers` 转为通用 `sources`，把 `entries.paper_id` 迁为 `source_id`。沿用旧试卷、词条及关联 ID，保留六级年月与套卷的唯一约束；不要把文章标题作为唯一约束。先生成可恢复的旧数据备份，迁移失败整体回滚。
2. 保持 `words` 中英文归一化和掌握状态的全局唯一性。每篇文章的释义归属于对应关联记录，保留 `(source_id, word_id)` 唯一约束；同词跨文章、跨考试共享复习进度，语境释义分别保存。删除文章只移除该来源的关联。
3. 添加通用来源写接口，再让录入、预览、确认和学习范围接收 `sourceId`。旧 `paperId` 接口保留为六级兼容入口；两种参数同时提供且不一致时明确拒绝。模型预览仍只生成待核对词条，经现有确认流程保存。
4. 同步升级学习会话中的范围和来源快照，保留正在复习的队列、展开状态和修订号。结束的会话允许保留已删除来源的历史快照。来源标签校验需覆盖文章标题及其年份、题型等前缀，不能沿用当前六级标签的 100 字符上限。
5. 将备份升级为 v3（v2 已用于分轮学习与笔记），加入来源字段，同时支持导入 v1/v2 并转换为六级来源。未知版本明确拒绝，恢复前继续自动备份；不得让旧版导出逻辑静默遗漏文章。
6. 在以上链路全部完成后，将对应类型的 `storageReady` 改为 `true`，增加文章管理和按考试筛选的界面。上线前验证旧库升级、v1/v2/v3 恢复、跨考试同词、删除来源、会话续学、模型预览不落库及窄屏操作。

## 项目与接口

- `server.js`：HTTP 服务、JSON API、静态资源、安全响应头与同源限制。
- `lib/parser.js`：纯文本格式解析；`lib/store.js`：SQLite、事务、学习状态机与备份校验。
- `lib/llm.js`：可选模型适配器、配置状态、结果校验与请求限制。
- `lib/sources.js`：来源协议、考试类型、来源标签与整理提示词；`lib/errors.js`：共用接口错误。
- `lib/practice.js`：分轮记忆／拼写状态机与进度校验；`lib/review.js`：到期与间隔规则。
- `lib/learning.js`：偏好、笔记校验、学习日与统计；`lib/word-list.js`：筛选与 TXT 导出。
- `public/`：原生网页，无第三方脚本与字体依赖；朗读由设备语音服务处理。
- `test/`：Node.js 原生测试。

主要 JSON API：

| 接口 | 用途 |
| --- | --- |
| `GET /api/overview` | 试卷、来源、词条与笔记、学习会话、偏好和统计 |
| `PUT /api/preferences` | 保存目标、组数、拼写、口音和主题 |
| `PUT /api/words/:id/details` | 保存 `starred`、`note`、`example`、`translation` |
| `GET /api/source-types` | 来源协议版本、考试类型、存储可用状态及手动整理提示词 |
| `POST /api/papers` | 创建或取得已有试卷，传 `examMonth` 与 `volume` |
| `DELETE /api/papers/:id` | 删除试卷 |
| `PUT /api/entries/:id` | 编辑试卷词条，传 `english`、`meaning` |
| `DELETE /api/entries/:id` | 删除试卷词条 |
| `POST /api/import/preview` | 传 `paperId` 和 `text` 或修改后的 `rows` |
| `POST /api/import/confirm` | 传 `paperId`、已检查 `rows`、唯一 `requestId`；事务写入且重试幂等 |
| `POST /api/session` | `paperId`、`filter`、`size`；新流程加 `mode: "context"`，可选 `spelling`、`practice: "mixed" / "spelling"`、`retrySessionId` |
| `POST /api/session/action` | `sessionId`、`revision`、`action`，选择与拼写附带 `answer` |
| `GET /api/backup` | 下载完整备份 |
| `POST /api/backup/preview` | 校验备份并返回数量 |
| `POST /api/backup/restore` | 自动备份旧数据后事务恢复 |

搜索与筛选由前端对本机个人词库执行。新流程 `action` 支持 `choose`、`known`、`vague`、`unknown`、`correct`、`continue`、`spell`、`end`；旧流程支持 `next`、`reveal`、`remember`、`forget`、`end`。冲突返回 409，普通校验失败返回 400；错误格式为 `{ "error": "说明" }`。

测试或独立实例可通过 `CET6_DATA_PATH` 指定数据库文件路径，通过 `PORT` 设置端口。正式使用保持默认配置即可。
